Foodscan

Reads an ingredient list and reports how processed the product is on the NOVA scale (1 to 4). It reports processing level only, from the ingredient list. When the evidence is weak it says so and gives no group.

Examples:

Text is read in your browser (nothing is uploaded); small photos are enlarged first, and the first read takes a few seconds while the reader loads. If photo reading fails, paste the text instead. The text it reads is copied into the Paste tab so you can fix mistakes and press Analyse again.

This page is a browser copy of the Python foodscan classifier. A parity script runs both on the same texts and they must match; /*PARITY*/ of /*PARITY*/ matched at build time.

Groups follow the NOVA classification (University of Sao Paulo). Marker rules and sources are listed per result. Reference labels for any test set are provisional, not ground truth.
