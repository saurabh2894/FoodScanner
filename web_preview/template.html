Foodscan

Reads an ingredient list and reports how processed the product is on the NOVA scale (1 to 4). It reports processing level only, from the ingredient list. When the evidence is weak it says so and gives no group.

Examples:

Text is read in your browser with tesseract.js. If photo reading cannot start in this viewer, paste the text instead. Check the extracted text before trusting the result.

This page is a browser copy of the Python foodscan classifier. A parity script runs both on the same texts and they must match; 61 of 61 matched at build time.

Groups follow the NOVA classification (University of Sao Paulo). Marker rules and sources are listed per result. Reference labels for any test set are provisional, not ground truth.
