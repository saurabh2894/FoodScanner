yoghurt-24 (revised after review): recognition-only, 0 new heads. Bare "yoghurt" is NOT a row: the FAO clause names plain yoghurt, so only the explicit "plain yoghurt" ("plain yogurt" synonym) is placed, as Group 1 when sole. It is counted under the existing dahi head: the FSSAI clubbing list (https://foscos.fssai.gov.in/assets/docs/Revised%20Clubbing%20list%20of%20standardized%20products.pdf) puts Yoghurt and Plain Dahi (Curd) in one standardized category, "Fermented Milk including plain Yoghurt", 2.1.13(1)(a); flavoured yoghurt and flavoured dahi are one separate category (2.1.13(2)(C)(iv)). Secondary text of the older standard (https://foodsafetyhelpline.com/fermented-milk-products/) says the yoghurt type must be on the label "otherwise standards of plain Yoghurt shall apply"; the current primary text was not retrievable (fetch truncates before 2.1.13), so the bare word still abstains. Held: paneer, chhana, khoa, buttermilk, kefir, sour cream (no placement clause).
